# Azure Data Factory (ADF)

This folder contains orchestration pipelines, datasets, linked services, and trigger definitions for the Dennis project.

## Overview
* **Data Ingestion:** Automated pipelines to extract and load data into cloud storage and staging environments.
* **Orchestration:** End-to-end workflow execution, dependency management, and triggering of Databricks notebooks.
* **Integration:** Connectors and configurations linking source systems with downstream processing layers.
